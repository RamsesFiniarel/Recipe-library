# Recipe library

A web application to store all your recipes inside virtual cooking books. To be hosted on a local server at home and accessed by any device on your network, without requiring internet.

## Goals

- Gather all your recipes in one place, instead of scattered across notebooks, photos and websites.
- Find a recipe in seconds, by its name, an ingredient, the time available or the number of guests.
- Create a recipe with little effort: by hand, from photos, or from a website's address.
- Have your own cooking database: everything stays on the local server, backed up every day, and the application depends on no outside service (except if you import a recipe from a website's address).
